## Notebooks

| Notebook | Conteúdo |
|---|---|
| [Data_Wrangling_MBA](Data_Wrangling_MBA.ipynb) | **Data Wrangling com pandas (MBA USP/Esalq).** Resumo das funções de *data wrangling* da disciplina (renomear, selecionar, criar e categorizar variáveis, estatísticas, filtros, *merge*, duplicados, *melt* e encadeamento) e as atividades práticas com os indicadores do Banco Mundial e os catálogos de filmes e séries de *streaming*. |
| [ETL_Cleaning_and_Transformation](ETL_Cleaning_and_Transformation.ipynb) | **Transformação e limpeza de dados com pandas.** Transformação de dados semiestruturados (JSON aninhado, listas em colunas, números e datas em texto, extração com expressões regulares) e limpeza de uma base de clientes de telecomunicações: valores em branco, nulos, duplicados, *outliers* e codificação de variáveis categóricas. |
| [ETL_File_Formats_and_SQL](ETL_File_Formats_and_SQL.ipynb) | **Formatos de arquivos e exportação para SQL.** Leitura e escrita de dados com pandas em diferentes formatos (CSV, Excel, Google Sheets, JSON, HTML, XML e Parquet), detecção de *encoding*, uso de bancos de dados com SQLAlchemy e geração de scripts SQL `INSERT` a partir de DataFrames, incluindo a normalização de uma tabela de livros em autores, gêneros, livros e comentários. |

Para abrir no Colab: *Arquivo → Abrir notebook → GitHub*, informe `PRBerlanda/Python-Data-Focused-` e escolha esta branch. A primeira célula de cada notebook indica os dados necessários. Localmente: `pip install -r requirements.txt`.
